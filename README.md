# InventoryLite

A simple Java console application for tracking products and quantities.

## Features
- Add products
- View all products
- Search for a product
- Update product quantity
- Remove products
- Simple menu-driven interface

## Java Concepts
- Classes and objects
- ArrayList
- Methods
- Loops
- If/else and switch
- Scanner input
- Basic CRUD operations

## How to Run

Make sure Java is installed.

```bash
javac -d out src/inventorylite/*.java
java -cp out inventorylite.InventoryLite
```
